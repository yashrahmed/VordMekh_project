# Fine-grained object recognition

## Goal

Create a tool that allows training and fine-tuning models for very specific labels in a sample-efficient way. Primary use cases are aircraft and car make/model recognition.

## Version 1

- [ ] Build a system that can recognize an aircraft make and model using fewer than 20 images.
- [ ] Investigate connections to ARC AGI, since both problems require determining the relevant features from very few examples.
