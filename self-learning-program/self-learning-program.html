Things to check

  • 1.1: the reasoning-models book is by Sebastian Raschka, not Ruder (Manning page).
  • 1.2: DeepInfer is Apache 2.0, only about four days old, and supports only DeepSeek-V4.1-Flash on Nvidia SM100 and Huawei Ascend 950. It ships without a KV cache system, so use the PagedAttention paper for that. Confirm the repo URL resolves (coverage).
  • 2.1: I didn't find a specific Claude Code internals PDF. The VILA-Lab repo analyzes leaked source, so treat it as unofficial and possibly out of date. If you have the PDF's name, send it.
  • 2.2: I couldn't find a public MIT agents course; the only match (MAS.664) is behind a Canvas login. Berkeley's Agentic AI MOOC (Fall 2025) succeeds the Spring 2025 Advanced LLM Agents course. OpenClaw's ClawHub registry had a malware problem: Koi Security flagged 341 of 2,857 skills as malicious in February 2026, and later counts were higher. Review anything before installing it.
  • 2.3: pstack is Lauren Tan's. github.com/poteto/pstack returns 404, so I linked michael-denyer's Claude Code port, which resolves and credits the original. Swap in the original repo URL if you know it.
  • 4.2: the ASP link is Vladimir Lifschitz's Answer Set Programming, the book your exercises in VordMekh_project/projects/krr follow. I took the URL from your own krr README rather than a local PDF, since I found no book file on disk. The Potassco guide is a good syntax reference alongside it.
  • 3.2: the link uses the old 6.824 course number and may redirect to 6.5840.
  • 3.4: the agent-facing browser standard is WebMCP. Google and Microsoft co-developed it, and it lets a site expose tools to agents through navigator.modelContext. It's a Community Group draft in a Chrome origin trial, not a finished standard, and despite the name it doesn't use the MCP wire protocol. It pairs with 2.4-agent-tooling.
  • 6 / Bend: the project is early-stage and needs an NVIDIA GPU for the GPU path. A single aggregator reports a "Bend 2" launch with no primary announcement.
  • Unchecked: the Rust, Python and Blender links are the standard official docs, and the new URLs from the review were not individually opened.
